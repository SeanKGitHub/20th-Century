# 20th Century Event Analysis

This project analyses the major events from the 20th century by scraping and processing content from Wikipedia.

## 🔍 Project Goal

To scrape the [Key events of the 20th Century](https://en.wikipedia.org/wiki/Key_events_of_the_20th_century) Wikipedia article and analyse the relationships between countries based on their mention and co-occurrence in the context of global events.

## 📂 Notebooks

- `Scraping_20C.ipynb` — Scrapes the Wikipedia article and saves the raw event text.
- `NLP.ipynb` — Performs natural language processing on the raw event descriptions.
- `NER.ipynb` — Uses Named Entity Recognition to extract country names.
- `Network_Analysis.ipynb` — Builds and visualises a country network and analyses relationships and centrality.

## 📄 Data

- Output files (e.g., scraped text, processed CSVs) are generated by the notebooks and saved locally. These are excluded from the repo.
- Country demonym matching is based on [this list of country–nationality pairs](https://gist.github.com/consti/e2c7ddc64f0aa044a8b4fcd28dba0700#file-emoji_country_nationality_list-csv).
